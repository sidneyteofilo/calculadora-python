# Calculadora em Python

Meu primeiro projeto de calculadora interativa desenvolvido em Python durante meus estudos de lógica de programação.

## Funcionalidades

- Soma de dois números
- Subtração de dois números
- Multiplicação de dois números
- Divisão de dois números
- Verificação de divisão por zero
- Menu interativo com opção de retornar ou encerrar o programa

## Tecnologias utilizadas

- Python 3

## Como executar

1. Tenha o Python 3 instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python ProjetoCalculadora.py
```

## Objetivo

Este projeto foi desenvolvido para praticar conceitos fundamentais de programação, incluindo estruturas condicionais, laços de repetição, operadores matemáticos e entrada de dados.

O projeto faz parte da minha jornada de aprendizado em desenvolvimento de software.
